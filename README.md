# 어여우라지 케이스 스터디

정선아리랑 가사 속 정선을 실제 여행길로 옮기는 NFC 여행 안내 서비스 디자인의 전시용 케이스 스터디 사이트.

- 실행: `npm run dev` (포트 5195), `npm run build`
- 빌드 설정: 이 환경에 lightningcss 네이티브 바인딩이 없어 `build.minify: false`
- 화면 그림: 실제 서비스(https://jeongseon-arirang.vercel.app)를 모바일 폭으로 직접 열어 찍은 캡처(`public/img/live/`)와 기존 화면 자료

## 구성

| 번호 | 구간 | 내용 |
|---|---|---|
| 1 | 표지 | 서비스 이름, 한 줄 설명, 실제 답 화면 |
| 2 | 문제 | 설문 결과 두 줄, 흩어진 사이트 세 곳의 실제 화면과 주석 |
| 3 | 퍼소나 | 지은의 상황, 서비스가 짠 하루 |
| 4 | 질문 | 질문, 답, 날짜, 일정 네 화면과 주석 |
| 5 | 지도 | 장소 목록, 3D 지도, 길 안내 세 화면과 주석 |
| 6 | 장소 카드 | 사진, 네 탭, 소리, 정보, 다음 코스 |
| 7 | NFC 스티커 | 알림, 장소 화면, 가사와 소리, 현장 사진 네 곳 |
| 8 | 패스 | 패스, 룰렛, 완주 카드 |
| 9 | 사진 퀴즈 | 문제와 정답 |
| 10 | 직접 사용 | 실제 서비스 화면을 이 자리에서 조작 |
| 11 | 크레딧 | 서비스, 과목, 조사, 자료 |

## 주석 방식

화면의 한 지점에 점을 찍고 실선으로 옆 카드에 잇는다. 카드는 작은 색 태그와 두 줄 설명(눌렀을 때 바뀌는 내용, 그렇게 만든 이유).
태그 색은 파랑이 눌러서 바뀌는 곳, 노랑이 읽는 정보, 빨강이 출처다. 기능마다 단계 탭이 있고 화면에 들어와 있으면 9초마다 다음 단계로 넘어간다.
980px 이하에서는 선 대신 점과 카드에 같은 번호를 붙여 화면 아래에 카드를 나열한다.
