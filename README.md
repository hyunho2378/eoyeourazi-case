# 어여우라지 케이스 스터디

정선아리랑 가사 속 정선을 실제 여행길로 옮기는 NFC 여행 안내 서비스 디자인의 전시용 케이스 스터디 사이트입니다.

- 배정 사례: 플러스엑스 EQL(id `eql`), 원본 https://www.plus-ex.com/source/iframe/portfolio/eql.html
- 원본 측정 문서: `_ref/분석.md` (원본 HTML과 CSS, JS는 `_ref/`에 그대로 보관)
- 실행: `npm run dev` (포트 5195), `npm run build`
- 빌드 설정: 이 환경에 lightningcss 네이티브 바인딩이 없어 `build.minify: false`

### 바꾼 화면

- 개요: 휴대폰 세 대 화면을 오른쪽 작은 칸에서 전체 폭으로 옮기고 박물관 사진을 글 옆에 둠
- 세 사이트 구간: 회색 판 머리에 정선아리랑시장 장날 사진을 넣어 글만 있는 화면을 없앰. 사이트 캡처 세 장을 판 전체 폭으로 키우고 설명은 캡처 아래 2칸으로 내림
- A 구간 머리: 하루 일정 답 화면(mk03)을 제목 옆에 둠
- 노래 속 장소 NFC: 글 아래에 아리랑박물관 장소 화면(mk06)을 더하고 오른쪽 화면을 44vw로 키움
- 완주 카드 구간: 제목과 설명을 2칸 머리로 바꾸고 화면 두 대를 세 대(완주 카드, 패스 스탬프, 실제 패스)로 늘림
- 닫는 장: 흰 바탕 제목과 사진을 합쳐 사진 위 글로 바꿈
- 섹션 사이 여백을 166px에서 104px로, 판 안쪽 여백도 줄여 빈 화면을 없앰
