# 어여우라지 케이스 스터디

정선아리랑 가사 속 정선을 실제 여행길로 옮기는 NFC 여행 안내 서비스 디자인의 전시용 케이스 스터디 사이트.

- 실행: `npm run dev` (포트 5195), `npm run build`
- 빌드 설정: 이 환경에 lightningcss 네이티브 바인딩이 없어 `build.minify: false`
- 화면 그림: 실제 서비스(https://jeongseon-arirang.vercel.app)를 모바일 폭으로 직접 열어 찍은 캡처(`public/img/live/`)와 기존 화면 자료

## 구성

서비스디자인 케이스 스터디 흐름. 현장과 문제에서 시작해 사용자와 여정, 콘셉트, 이해관계자 구조, 핵심 화면, 정책 제안으로 이어진다.

| 번호 | 구간 | 내용 |
|---|---|---|
| 1 | 표지 | 서비스 이름, 한 줄 설명, 실제 답 화면 |
| 2 | 현장 | 현장 조사 사진과 인터뷰에서 들은 말 |
| 3 | 문제 | 설문 결과 문장, 흩어진 사이트 세 곳의 실제 화면과 주석 |
| 4 | 문제 정의 | 한 번에 보여야 하는 정선, 막힌 곳과 해결 |
| 5 | 퍼소나 | 지은의 상황, 불편, 필요 |
| 6 | 사용자 여정 | 비교, 계획, 도착, 관람, 귀가 다섯 단계의 지금과 어여우라지가 있을 때 |
| 7 | 서비스 콘셉트 | 질문에서 패스까지 다섯 접점 |
| 8 | 이해관계자 | 여행자, 정선군, 재단과 보존회, 박물관과 공연장, 코레일, 시장 상점이 주고받는 내용 |
| 9 | 핵심 화면 | 질문과 답, 하루 일정, 장소 화면, 길 안내, 패스. 화면마다 두세 곳에만 주석 |
| 10 | 직접 사용 | 실제 서비스 화면을 이 자리에서 조작 |
| 11 | 정책 제안 | 스티커가 놓이는 정선읍 네 곳, 정선군과 재단에 하는 제안, 석 달과 1년, 3년 단계 |
| 12 | 크레딧 | 서비스, 과목, 조사, 자료 |

## 주석 방식

화면의 한 지점에 점을 찍고 실선으로 옆 카드에 잇는다. 카드는 작은 색 태그와 두 줄 설명.
태그 색은 파랑이 눌러서 바뀌는 곳, 노랑이 읽는 정보, 빨강이 출처와 막힌 지점이다.
980px 이하에서는 선 대신 점과 카드에 같은 번호를 붙여 화면 아래에 카드를 나열한다.
