## 3. 공통 연출 문법과 구현 방법

### 문법 1. 정적 배치가 기본
- EQL은 스크롤에 묶인 움직임이 거의 없음 [측정]. 사진과 화면이 크게 놓이고 글은 옆에 짧게 붙는 구성으로 읽힘
- 구현: 섹션마다 2칸 그리드나 가운데 정렬 판, 큰 그림과 짧은 글

### 문법 2. 진입 tween(코드에만 있음)
- `y: 50`, `opacity: 0`, 길이 1.5초, `delay: idx*0.2`, start `top bottom` [측정]. 원본 문서에는 대상이 없음
- 우리 적용: 같은 값을 제목과 본문 묶음에 걸되, 지연은 섹션 안 순번으로 매김(문서 전체 순번이면 뒤쪽 요소가 수 초씩 늦어짐)

### 문법 3. 보일 때만 재생
- start `top 95%`, end `bottom 5%`, 안에 들어오면 play, 나가면 pause [측정]
- 우리 적용: 영상 대신 실제 서비스 iframe을 같은 범위에서 처음 들어올 때 불러옴(한 번 불린 뒤에는 유지)

### 문법 4. 끝없이 흐르는 사진 띠
- Swiper 값 그대로(8장, 간격 5px, 3000ms, 선형, 손으로 못 끎) [측정]
- 우리 적용: 같은 값의 CSS 선형 흐름으로 다시 씀. 화면 폭 768 미만은 3장 보기

### 문법 5. 기기 틀
- 원본은 검정 5px 선 테두리와 그림자 [측정]
- 우리 적용: 화면 금지 규칙(테두리 금지) 때문에 선 대신 검정 면 안쪽 여백(같은 두께)으로 틀을 만들고 그림자 값은 그대로

## 5. 상자 없이 정보를 나누는 방식
- 구분은 선이 아니라 면 색(#F6F6F6 판, 회색 그라데이션 판)과 큰 여백(166px 안팎)으로 함
- 목록은 상자에 넣지 않고 번호, 큰 단어, 소제목, 두 줄 설명을 세로로 쌓음
- 사진 위 글은 반투명 판이나 30% 검정 덮개로 대비를 냄

## 6. 우리 작품에 옮기지 않은 요소
- EQL 로고, 사진, 영상, 단어 띠 그림, 아이콘 svg, GT America 글꼴, 영문 문구 전부
- 원 아이콘(A B C α, 원 숫자): 화면 금지 규칙 7(원형 아이콘 배경) 때문에 숫자 글자로 바꿈
- 001~004 검은 꼬리 이름표: 알약과 라벨 금지 때문에 숫자 글자로 바꿈
- principle 회색 그라데이션: 장식 그라데이션 금지 때문에 단색 #F4F5F6 판
